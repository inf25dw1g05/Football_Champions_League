# C2 : Resources

Nesta secção apresentamos os recursos disponibilizados no nosso projeto.  
Todos os endpoints foram documentados no ficheiro `openapi.yaml` e implementados através de controladores e serviços específicos.

A API inclui recursos relacionados com:

---

## 1. Equipas
Permite:
- Criar uma equipa
- Consultar uma equipa
- Listar jogos de uma equipa
- Listar jogadores de uma equipa
- Listar todas as equipas ( com opções de filtragem por país, grupo ou ainda treinador)
- Atualizar uma equipa
- Remover uma equipa

Inclui também a relação entre jogadores, treinadores e grupos.

---

## 2. Jogadores
Permite:
- Criar um jogador
- Remover um jogador
- Listar eventos associados a um jogador específico (com o filtro por tipo de evento ou pelo id de jogo)
- Consultar um jogador
- Listar todos os jogadores (com opções de filtragem por posição por nacionalidade ou ainda pelo id da equipa do jogador)
- Atualizar um jogador

---

## 3. Jogos
Permite:
- Criar um jogo
- Apagar um jogo
- Consultar um jogo com a possibilidade de filtrar tanto por equipa, como por data, como por estadío ou ainda por resultado
- Listar todos os jogos com a possibilidade de filtrar tanto por equipa, como por data, como por grupo ou ainda por estado do jogo (exemplo se o jogo ainda não tenha occorido)
- Atualizar as informações de um jogo específico

---

## 4. Eventos de Jogo
Permite:
- Criar um evento
- Apagar um evento
- Listar todos os eventos de um jogo (com filtro por tipo de evento ou por id de jogador)
- Atualizar um evento (ex.: anular um golo)

---

## 5. Estatísticas
Permite:
- Listar estatísticas disciplinares (jogadores com mais sanções)
- Consultar a classificação por grupo
- Listar os jogadores com mais assistências
- Listar os jogadores com mais golos

---

## 6. Estrutura Docker
A API é suportada por um sistema multicontainer composto por:
- `api-service` (backend)
- `db-service` (base de dados)
- volumes persistentes para armazenamento

Toda a interação com os recursos é automaticamente disponibilizada após executar:
`docker compose up`
